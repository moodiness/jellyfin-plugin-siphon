Siphon

Stremio addons in Jellyfin. Connect your addons to bring their catalogs, metadata and playback sources into your media library.

Mixed catalogs and IMDb, TMDB, TVDB, MyAnimeList and addon-specific identifiers are supported. Playback currently uses server-proxied HTTP(S) files and HLS; torrent and external-player sources are not played.

Addon URLs may contain credentials. They are masked here but stored in Jellyfin's plugin configuration. Protect configuration backups.

Configuration
HTTP(S) address reachable by both Jellyfin and your players, including Jellyfin's base path. In Docker, localhost is not the host machine.
Absolute server directory for managed movie files. Add this folder to a Jellyfin Movies library.
Separate absolute server directory for managed episodes. Add this folder to a Jellyfin Shows library.
Optional security exceptions for trusted private-network addons or streams. No wildcards, URLs, or CIDR ranges. Save these exceptions before validating a private addon.
Caution: opt in only if you want previously imported items removed when they are no longer returned by any enabled subscription. Other library files are not managed by Siphon.

Addons and catalogs

Paste an HTTP(S) or stremio:// manifest URL. stremio:// is fetched through HTTPS; the configured path and credentials are preserved.

Changes are not active until saved. Sync uses the last saved configuration.
